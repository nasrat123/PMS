# Project Instructions

You are working on an existing Hospital
Management System (PMS).

## Technology Stack

- Python 3.13
- Django 5.2
- SQLite
- HTML
- CSS
- JavaScript
- Bootstrap

## Project Structure

Main Django project: pms
Main application: pharmacy

## Important Rules

1. Always inspect existing code before making changes.

2. Never rewrite existing files unnecessarily.

3. Preserve existing functionality.

4. Do not create duplicate models, views,
   URLs, or templates.

5. Follow the existing project architecture.

6. Use Django best practices.

7. Use transaction.atomic() for financial
   and inventory-related operations where needed.

8. Protect views using the existing
   authentication and group permissions.

9. Use select_for_update() where appropriate
   for inventory operations.

10. Write tests for important changes.

## Development Workflow

Before implementing a feature:

1. Analyze the existing implementation.
2. Identify bugs and weaknesses.
3. Explain the proposed solution.
4. Identify the files that need modification.
5. Implement only the required changes.
6. Run appropriate tests.
7. Explain all modifications.
